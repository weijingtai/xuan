# 大六壬占卜应用 - 产品需求文档 (PRD)

## 文档信息
- **版本**: 1.0
- **最后更新**: 2025-09-30
- **产品名称**: 大六壬 (Da Liu Ren Divination)
- **技术架构**: MVVM + Clean Architecture
- **平台**: Flutter (iOS/Android/Web)

---

## 1. 产品概述

### 1.1 产品定位
大六壬是中国古代三大占卜术之一，本应用为用户提供专业、准确、易用的大六壬占卜服务。通过移动端应用实现传统占卜方法的数字化，为用户提供占卜计算、盘面展示、结果解读等功能。

### 1.2 核心价值
- **准确性**：严格遵循古籍《御定大六壬》等经典文献的计算规则
- **专业性**：完整实现四课、三传、九宗门等大六壬核心理论
- **易用性**：简化传统占卜流程，提供直观的UI交互
- **可靠性**：基于MVVM架构，保证应用稳定性和可维护性

### 1.3 目标用户
- **主要用户**：对中国传统文化、命理学、占卜术有兴趣的爱好者
- **次要用户**：专业命理研究者、风水师、传统文化工作者
- **使用场景**：个人占卜、学习研究、专业咨询

### 2.1 核心功能模块

#### 2.1.1 时间选择模块
**功能描述**：用户可以选择起卦时间（年月日时）

**功能要点**：
- 支持公历日期选择
- 自动转换为农历（天干地支）
- 支持手动输入特定时间
- 默认使用当前系统时间
- 显示节气信息
- 显示四柱八字（年柱、月柱、日柱、时柱）

**交互流程**：
1. 用户点击时间选择器
2. 系统展示日期时间选择界面
3. 用户选择年月日时
4. 系统自动计算对应的天干地支
5. 系统触发占卜盘面计算

**验收标准**：
- 日期时间准确转换为天干地支
- 农历计算符合传统历法规则
- 节气判断准确

#### 2.1.2 占卜盘面计算模块
**功能描述**：根据选定时间自动计算大六壬占卜盘面

**核心计算逻辑**：

**2.1.2.1 月将定位**
- 根据节气确定月将（月建）
- 月将列表：寅申巳亥子午卯酉辰戌丑未

**2.1.2.2 天地盘生成**
- 地盘：十二地支固定排列（子丑寅卯辰巳午未申酉戌亥）
- 天盘：根据时辰和月将旋转生成
- 计算规则：以月将加时辰，顺时针布局

**2.1.2.3 贵人定位**
- 昼夜贵人规则："甲戊庚牛羊、乙己鼠猴乡、丙丁猪鸡位、壬癸兔蛇藏、六辛逢马虎"
- 根据日干和时辰判断昼贵人或夜贵人
- 贵人落宫位置决定十二神将顺逆排列

**2.1.2.4 十二神将配置**
- 十二神将：贵人、腾蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后
- 贵人为首，顺时针或逆时针排列
- 排列规则：贵人落地盘巳-戌为顺排，亥-辰为逆排

**2.1.2.5 四课计算**
四课是大六壬的核心，包括：

**第一课（日课）**：
- 地盘：日干寄宫（十干寄宫法）
- 天盘：日干寄宫对应的天盘地支

**第二课（日神课）**：
- 地盘：第一课的天盘地支
- 天盘：该地支对应的天盘地支

**第三课（支课）**：
- 地盘：日支
- 天盘：日支对应的天盘地支

**第四课（支神课）**：
- 地盘：第三课的天盘地支
- 天盘：该地支对应的天盘地支

**特殊情况判断**：
- **伏吟**：四课中有两课以上天地相同（如寅上寅、申上申）
- **反吟**：四课中有两课以上天地相冲（如寅上申、申上寅）
- **四课不备（别责）**：四课中有重复，实际只有三课或两课
- **四课齐备**：四课互不相同

**贼克关系判断**：
- **贼**（下克上）：地支五行克天支五行
- **克**（上克下）：天支五行克地支五行
- **遥克**：天支五行与日干五行有克制关系

**2.1.2.6 三传计算（九宗门法）**
三传是占卜结果的关键，按九宗门规则依次判断：

**1. 伏吟门**：
- 条件：四课为伏吟格局
- 有克：日干上神为初传，按刑法取中末传
- 无克：阳日取干上神，阴日取支上神为初传
- 特殊格：自任格、杜传格

**2. 反吟门**：
- 条件：四课为反吟格局
- 有克：按贼克法取用
- 无克：取日支三合局孟神之冲（驿马）为初传

**3. 八专门**：
- 条件：干支同位（甲寅、庚申、癸丑、丁未、己未日）
- 有克：按贼克法
- 无克：阳日顺数三神，阴日逆数三神

**4. 贼克门（蒿矢课、重审课、元首课）**：
- 元首课：仅一个克，直接取用
- 蒿矢课：仅一个贼，直接取用
- 重审课：一贼一克，取贼不取克
- 多贼多克：进入比用或涉害

**5. 比用门**：
- 多个贼克时，取与日干同阴阳的上神

**6. 涉害门（深浅、缀瑕、剑际、差微）**：
- 深浅法：统计上神回归地盘的克制次数
- 孟仲季法：克制次数相同时，优先取孟神
- 缀瑕法：无法区分时，阳日取干上神，阴日取支上神

**7. 遥克门（蒿矢课、贪蛇课）**：
- 蒿矢课：上神克日干
- 贪蛇课：日干克上神

**8. 别责门**：
- 条件：四课不备，且无贼克遥克
- 阳日：取日干五合之干的寄宫天盘为初传
- 阴日：取日支三合局下一位为初传

**9. 昴星门**：
- 所有方法都不适用时的兜底规则
- 阳日：酉上取初传
- 阴日：酉下取初传

**三传生成规则**：
- 初传确定后，中传为初传上神
- 末传为中传上神
- 形成三传顺次传递关系

**2.1.2.7 局数判断**
- 根据日干、时支、阴阳遁确定局数（1-12局）
- 每个局数对应不同的占卜意义

**验收标准**：
- 四课计算准确，符合传统规则
- 三传推导正确，九宗门判断准确
- 伏吟、反吟、八专等特殊格局识别准确
- 贼克关系判断正确
- 局数判定符合历法规则

## 3. 技术需求

### 3.1 架构设计

#### 3.1.1 整体架构
采用 **MVVM + Clean Architecture** 设计模式：

```
lib/
├── domain/                    # 领域层（业务逻辑）
│   ├── services/             # 领域服务
│   │   ├── calculators/     # ✅ 计算器层 - 单一职责
│   │   │   ├── base_calculator.dart
│   │   │   ├── lunar_calculator.dart        # 农历八字计算
│   │   │   ├── tian_di_pan_calculator.dart  # 天地盘计算
│   │   │   ├── gui_ren_calculator.dart      # 贵人神将计算
│   │   │   ├── four_class_calculator.dart   # 四课计算
│   │   │   └── three_chuan_calculator.dart  # 三传计算
│   │   └── da_liu_ren_calculation_service.dart  # ✅ 计算编排服务
│   ├── usecases/            # 用例（业务用例）
│   │   ├── base_usecase.dart
│   │   ├── calculate_divination_usecase.dart
│   │   └── load_divination_data_usecase.dart
│   └── repositories/        # 仓库接口（抽象）
│       └── da_liu_ren_repository.dart
├── data/                    # 数据层
│   ├── models/             # 数据模型
│   ├── repositories/       # 仓库实现
│   │   └── da_liu_ren_repository_impl.dart  # ✅ 真实计算逻辑
│   └── datasources/        # 数据源（本地/远程）
├── presentation/            # 表现层
│   ├── viewmodels/         # 视图模型（状态管理）
│   │   ├── base_viewmodel.dart
│   │   └── da_liu_ren_viewmodel.dart
│   ├── views/              # 视图（UI界面）
│   │   ├── da_liu_ren_view.dart  # ✅ MVVM视图
│   │   └── widgets/             # 可复用组件
│   │       ├── datetime_selector_widget.dart
│   │       ├── divination_display_widget.dart
│   │       ├── loading_widget.dart
│   │       └── error_widget.dart
└── di/                      # 依赖注入
    └── dependency_injection.dart  # ✅ 完善的DI配置
```

**架构优势**：
- ✅ 职责分离，易于维护
- ✅ 业务逻辑与UI解耦
- ✅ 便于单元测试
- ✅ 支持多平台扩展
- ✅ Calculator层可独立测试和复用
- ✅ Service层编排清晰,步骤明确

#### 3.1.2 核心技术栈
- **Flutter**: 3.0.2+
- **状态管理**: Provider (ChangeNotifier)
- **农历计算**: lunar ^1.7.3
- **函数式编程**: fpdart ^2.0.0
- **JSON序列化**: json_serializable
- **数据库**: Drift (可选，用于历史记录)
- **UI组件**:
  - animated_custom_dropdown (下拉选择器)
  - board_datetime_picker (日期时间选择)
  - flutter_shakemywidget (摇卦动画)

### 3.2 数据模型

#### 3.2.1 核心模型类
- **DaLiuRenKePan**: 占卜盘面主模型

## 7. 风险与挑战

### 7.1 技术风险
- **风险**: 复杂的占卜算法计算性能问题
- **应对**: 优化算法、使用缓存、异步计算

### 7.2 数据风险
- **风险**: 大数据文件加载导致启动缓慢
- **应对**: 懒加载、数据压缩、分块加载

### 7.3 用户体验风险
- **风险**: 专业术语过多，用户理解困难
- **应对**: 提供新手模式、术语解释、视频教程

### 7.4 法律合规风险
- **风险**: 占卜类应用可能受到监管限制
- **应对**: 明确学习研究定位、添加免责声明、遵守平台规则

## 9. 附录

### 9.1 术语表
- **大六壬**: 中国古代三大占卜术之一，与奇门遁甲、太乙神数并称
- **四课**: 大六壬占卜的基础，由日课、日神课、支课、支神课组成
- **三传**: 初传、中传、末传，是占卜结果的核心
- **九宗门**: 推导三传的九种方法：伏吟、反吟、八专、贼克、比用、涉害、遥克、别责、昴星
- **天地盘**: 天盘和地盘，用于表示十二地支的动态关系
- **月将**: 根据节气确定的月建地支
- **贵人**: 十二神将之首，决定神将排列顺逆
- **寄宫**: 天干寄居地支的规则，如甲寄寅、乙寄辰等
- **伏吟**: 天盘地支与地盘地支相同的格局
- **反吟**: 天盘地支与地盘地支相冲的格局
- **贼克**: 地支五行克天支五行（下克上）
- **克**: 天支五行克地支五行（上克下）
