# 九宗门
## 涉害法
### 涉害说明
在大六壬中，涉害法是确定初传（发用）的重要方法，主要用于四课中存在多个贼克且无法通过比用法决疑的情况。深浅法与孟仲法是涉害法中的两种核心操作方式，二者的根本区别在于判断依据和操作逻辑的不同。以下从多个维度深入解析：
一、核心定义与根本逻辑
1. 深浅法（涉害归本家法）
定义：通过计算天盘地支回归地盘本位过程中所受克害的次数或程度，取受克最深者为初传。
逻辑：
强调实际克害的强度，认为受克次数多或路径复杂者，矛盾更突出，应优先发用。例如，某地支在回归本位时途经多个克它的地支，则涉害更深。
操作步骤：
遍历天盘地支回归地盘本位的路径，统计受克次数。
比较涉害深浅，取受克最多者为用。
若涉害相同，进一步考虑孟仲季或柔辰刚日规则。
2. 孟仲法（孟仲季直取法）
定义：根据地支的孟、仲、季属性（寅申巳亥为孟，子午卯酉为仲，辰戌丑未为季），按孟→仲→季的优先级直接确定初传，不取季位。
逻辑：
强调地支的气性强弱，认为孟位（四立之时）气最强且纯，仲位次之，季位最弱。因此，孟位发用代表事情初起，仲位代表事中，季位因气衰不取。
操作步骤：
直接按孟、仲、季顺序选择，孟位优先。
若涉害相同且都在孟位，取干上神；若都在仲位，取仲位中较近者。
二、核心区别对比
维度	深浅法	孟仲法
判断依据	受克次数或程度（实际克害强度）	地支的孟仲季属性（气性强弱）
侧重点	过程分析（克害路径与深度）	结果导向（事情阶段与气性）
操作复杂度	需遍历地盘计算克数，步骤繁琐	直接按孟仲季顺序选择，简便高效
历史演变	隋唐前主流（如《六壬大全》）	唐宋后兴起（如陈公献《大六壬指南》）
现代应用	学术研究或复杂课式分析	主流实践（因简易且常验）
三、具体操作差异解析
1. 深浅法的遍历规则
案例：甲辰日四课中，戌加寅（上克下）与子加辰（下贼上）俱比日，需用涉害法。
戌的涉害路径：从寅出发，经卯、辰、巳、午、未，回归戌位，受克四重（寅、卯、乙、辰）。
子的涉害路径：从辰出发，经巳、午、未、申、酉、戌，回归子位，受克五重（辰、戊、巳、未、戌）。
结论：子涉害更深，取子为初传。
2. 孟仲法的优先级逻辑
案例：丁卯日四课中，丑加卯（下贼上）与亥加丑（下贼上）俱比日。
丑的属性：仲位（子午卯酉）。
亥的属性：孟位（寅申巳亥）。
结论：优先取孟位亥为初传，即使亥的涉害次数可能少于丑。
3. 涉害相同的处理
深浅法：若涉害次数相同，进一步比较孟仲季或柔辰刚日规则。例如，戊辰日四课中，子加巳与午加亥俱比日且涉害相同，阳日取干上子为用。
孟仲法：若涉害相同且都在孟位，取干上神；若都在仲位，取仲位中较近者。例如，丙子日四课中，子加巳与寅加未涉害相同，子居孟位（巳为孟），取子为用。
四、流派争议与实践倾向
1. 历史分歧
深浅法：以《六壬大全》为代表，主张 “涉害行来本家止，路逢多克为用取”，强调实际克害深度。
孟仲法：以陈公献、邵彦和为代表，主张 “孟深仲浅季当休”，直接按孟仲季顺序选择。
2. 现代观点
徐伟刚：主张 “两法参合”，先取孟仲，再察涉害深浅。
多数实践者：倾向孟仲法，因其简便且符合六壬重结果的特点。例如，现代排盘软件多默认孟仲法。
3. 争议焦点
深浅法的合理性：部分学者认为，涉归本家取害深与式盘原理不符，因天盘地支无需转动。
孟仲法的片面性：忽略实际克害程度，可能导致初传选择偏差。
五、实际应用场景
1. 深浅法适用场景
需剖析事情发展细节（如疾病、官讼的复杂过程）。
四课中季位涉害明显更深（如季位受克次数远超孟仲）。
学术研究或验证古法（如《六壬大全》案例还原）。
2. 孟仲法适用场景
快速确定事情阶段（孟为初、仲为中、季为末）。
日常占验（如求财、行人），需高效决策。
遵循主流传承（如陈公献、邵彦和案例）。
六、总结
深浅法是技术派，通过量化克害程度揭示矛盾本质，适合复杂课式分析；孟仲法是实用派，以气性强弱为导向，适合快速决断。
两者并无绝对对错，关键在于结合占验需求与传承脉络。现代实践中，孟仲法因简便高效更受青睐，但深浅法在学术研究中仍具价值。
最终，六壬的核心在于 “活变”，需根据课传组合、神将关系综合判断，而非拘于一法。
### 涉害程序
在大六壬中，涉害法的核心是从四课中多个贼克关系中筛选出矛盾最突出的初传。深浅法、孟仲法、两法参合三种方式实现 “涉害” 的逻辑与操作路径差异显著，以下从实现原理、具体步骤、争议焦点三方面展开：
一、深浅法（涉害归本家法）`SheHaiStrategy#COMPREHENSIVE`
1. 实现原理
核心逻辑：天盘地支回归地盘本位时，受克次数越多或路径越复杂，矛盾越激烈，需优先发用。
深层依据：六壬式盘模拟天地运行，天盘地支转动回归本位的过程象征事物发展的阻力与曲折。例如，某地支在回归途中遭遇多次克害，如同人涉水过河时遭遇险滩，需重点关注。
2. 操作步骤
第一步：遍历路径
从四课的天盘地支出发，沿顺时针方向在地盘上逐位移动，直至回到本位。例如，天盘戌加寅，需从寅出发，经卯、辰、巳、午、未，最终回到戌位。
第二步：统计克数
记录路径中每一步的克害关系：
上克下：地盘地支克天盘地支（如寅木克戌土）。
下贼上：天盘地支克地盘地支（如子水克辰土）。
例如，甲辰日中，子加辰的路径受克五重（辰、戊、巳、未、戌），涉害更深。
第三步：比较深浅 
取受克次数最多者为初传。若涉害相同，阳日取干上神，阴日取支上神（如戊辰日取干上子）。
3. 争议焦点
路径合理性：部分学者认为，天盘地支无需实际转动，深浅法的遍历规则与式盘原理不符。
计算复杂度：需逐位统计克数，操作繁琐，尤其在复杂课式中易出错。
4. 涉害相同：若涉害次数相同，进一步比较孟仲季或柔辰刚日规则。例如，戊辰日四课中，子加巳与午加亥俱比日且涉害相同，阳日取干上子为用。
二、孟仲法（孟仲季直取法）`SheHaiStrategy#MENG_PRIORITY`
1. 实现原理
核心逻辑：根据地支的孟仲季属性（寅申巳亥为孟，子午卯酉为仲，辰戌丑未为季），按孟→仲→季的优先级直接取初传，不取季位。
深层依据：孟位代表五行初气（如寅为春初木气），气性最强且纯；仲位次之（如卯为春中木气）；季位气衰不取。例如，孟位发用象征事情初起，仲位象征事中。
2. 操作步骤
第一步：分类孟仲季
分析四课天盘地支对应的地盘地支属性。例如，丁卯日四课中，亥加丑的地盘丑为季位，但天盘亥为孟位，需优先考虑。
第二步：按序选择
有孟位则取孟位（如亥加丑，取亥为用）。
无孟位则取仲位（如子加辰，取子为用）。
季位无论深浅均不取。
第三步：涉害相同处理
若孟位涉害相同，取干上神（如丙子日取干上子）。
若仲位涉害相同，取距离日干较近的仲位（如乙巳日取午而非子）。
3. 争议焦点
忽略实际克害：仅以气性强弱为导向，可能导致初传与实际矛盾脱节。例如，季位涉害极深时，孟仲法仍不取季位。
4. 涉害相同：若涉害相同且都在孟位，取干上神；若都在仲位，取仲位中较近者。例如，丙子日四课中，子加巳与寅加未涉害相同，子居孟位（巳为孟），取子为用。
历史演变：唐宋后兴起，与隋唐前主流的深浅法形成鲜明对比。
三、两法参合（孟仲为纲，深浅为目） `SheHaiStrategy#COMBINED_APPROACH`
现代
1. 实现原理
核心逻辑：以孟仲法为优先筛选框架，再以深浅法验证涉害程度，兼顾气性与实际克害。
深层依据：孟仲法快速定位事情阶段，深浅法细化矛盾强度，两者互补。例如，徐伟刚主张 “先取四孟，再察涉害”，既把握气性又避免片面性。
2. 操作步骤
第一步：孟仲筛选
按孟→仲→季顺序选择候选初传。例如，四课中存在孟位（寅）和仲位（子），优先取寅为候选。
第二步：深浅验证
对候选初传计算涉害次数。若孟位涉害明显更深，则取孟位；若涉害相同或仲位更深，则需调整。
第三步：综合决断
若孟位涉害足够深，直接取孟位（如丁卯日取亥）。
若仲位涉害显著超过孟位，破例取仲位（如甲辰日取子）。
