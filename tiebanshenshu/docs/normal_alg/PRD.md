# 铁板神数条文计算方案产品需求文档 (PRD)

## 1. 文档概述

### 1.1 文档信息
- **项目名称**: 铁板神数条文计算系统
- **文档版本**: v1.0
- **创建日期**: 2025-10-10
- **最后更新**: 2025-10-10

### 1.2 产品概述
本系统提供五种不同流派的铁板神数条文计算方案，包括：
1. **数据源展示** - 展示八字基础数据
2. **日干支卦** - 基于日柱干支变卦取数法
3. **四柱天干** - 基于四柱天干组合取数法
4. **太玄四柱** - 基于太玄纳甲取数法
5. **八卦加则** - 基于四柱装卦加则取数法（爻序法+纳甲法）

## 2. 业务背景

### 2.1 业务目标
为用户提供多种铁板神数条文计算方法，支持不同流派的取数算法，让用户可以对比不同算法的计算结果。

### 2.2 目标用户
- 铁板神数研究者
- 命理学爱好者
- 算法开发人员

### 2.3 使用场景
- 用户输入八字信息，系统自动计算并展示多种算法的条文结果
- 用户可以在不同算法之间切换对比
- 用户可以刷新重新计算结果

## 3. 功能需求

### 3.1 核心功能模块

#### 3.1.1 数据源展示模块
**功能描述**: 展示用于计算的八字基础数据

**详细需求**:

- 展示时间信息（标准时间、时区）

**用户交互**:

- 支持下拉刷新所有数据

#### 3.1.2 日干支卦计算模块
**功能描述**: 基于日柱干支，通过变卦取数法计算条文编号

**算法原理**:
1. 提取日柱的天干和地支
2. 天干配下卦，地支配上卦，组成基本卦（64卦之一）
3. 计算基本卦的互卦
4. 基本卦的上下卦取后天卦数（千位、百位）
5. 互卦的上下卦取先天卦数（十位、个位）
6. 组合成四位基础数
7. 应用条文计算配置生成条文列表（默认：基础数 ± 1000）

**详细需求**:
- 输入：日柱干支（JiaZi对象）
- 输出：基础数 + 条文列表
- 条文计算配置：
  - 标准配置：基础数 ± 1000
  - 简化配置：仅基础数
  - 扩展配置：基础数 ± 500、± 1000、± 2000

**用户交互**:
- 展示基础数计算过程
- 展示条文列表
- 支持下拉刷新
- 支持展开/收起详情

#### 3.1.3 四柱天干计算模块
**功能描述**: 基于四柱天干，通过天干配数法计算条文编号

**算法原理**:
1. 提取四柱天干（年干、月干、日干、时干）
2. 天干配数规则：甲1、乙6、丙2、丁7、戊3、己8、庚4、辛9、壬5、癸0
3. 按"月日时年"顺序排列，组合成四位基础数
4. 应用条文计算配置生成条文列表（默认：基础数 + 96*n，n=0-7）
5. 特殊处理：基础数插入条文列表首位

**详细需求**:
- 输入：八字四柱（EightChars对象）
- 输出：基础数 + 条文列表
- 条文计算配置：
  - 标准配置：基础数 + 96*n (n=0-7)，共8个条文
  - 简化配置：基础数 + 96*n (n=0-3)，共4个条文
  - 扩展配置：基础数 + 96*n (n=0-10)，共11个条文

**用户交互**:
- 展示四个天干的配数过程
- 展示基础数计算
- 展示条文列表（基础数在首位）
- 支持下拉刷新
- 支持展开/收起详情

#### 3.1.4 太玄四柱计算模块
**功能描述**: 基于四柱干支，通过太玄纳甲法计算条文编号，支持两种纳甲方案

**算法原理**:
1. 将四柱每柱的天干和地支分别配卦
   - 天干配卦：壬甲从乾数，乙癸向坤求，庚来震上里，辛在巽方留，己从离门起，戊以坎为头，丙须艮处出，丁向兑家收
   - 地支配卦：亥子坎宫寅木震，巳午离门丑在坤，卯酉乾金辰是兑，未申艮宫戌巽真
2. 组卦：同一柱的天干为上卦，地支为下卦
3. 纳甲配干支（两种方案）：
   - **方案A - 年干阴阳纳甲**：根据年干阴阳选择纳甲天干（阳年用 yangGuaYaoTianGan，阴年用 yinGuaYaoTianGan）
   - **方案B - 传统内外卦纳甲**：根据当前卦的内外卦阴阳选择纳甲天干（阳卦用 outerGuaYaoTianGan，阴卦用 innerGuaYaoTianGan）
   - 地支配置：两种方案都使用 innerGuaYaoDiZhi（下卦）和 outerGuaYaoDiZhi（上卦）
4. 太玄数计算：每爻的干支取太玄数相加（和为10则不计）
5. 上卦三爻数之和为上数，下卦三爻数之和为下数
6. 组合成基础数：上数*100 + 下数
7. 每柱产生2个基础数（年干阴阳纳甲1个 + 传统内外卦纳甲1个），共8个基础数
8. 应用条文计算配置生成条文列表（默认：各基础数 ± 96）

**详细需求**:
- 输入：八字四柱（EightChars对象）
- 输出：8个基础数（4柱 × 2方法）+ 对应的条文列表
- 纳甲方案：
  - **年干阴阳纳甲**：根据年干阴阳决定天干配置
  - **传统内外卦纳甲**：根据当前卦内外卦阴阳决定天干配置
- 条文计算配置：
  - 标准配置：基础数 ± 96
  - 简化配置：基础数
  - 扩展配置：基础数 ± 96、± 192
- 特点：
  - 两种纳甲方案同时显示
  - 多选框控制显示（默认都显示）
  - 每个结果携带详细的计算过程
  - 区分纳甲方案来源

**计算过程数据**:
- 柱名称：年柱/月柱/日柱/时柱
- 干支：如"甲子"
- 纳甲方案：年干阴阳/传统内外卦
- 上卦：卦名及后天数
- 下卦：卦名及后天数
- 六爻详情：
  - 爻位（初、二、三、四、五、上）
  - 纳甲天干
  - 纳甲地支
  - 天干太玄数
  - 地支太玄数
  - 是否被过滤（和为10）
- 上卦总和
- 下卦总和
- 最终基础数

**用户交互**:
- 多选框控制显示：
  - "年干阴阳纳甲"（默认勾选）
  - "传统内外卦纳甲"（默认勾选）
- 展示8个计算结果（分组显示）
- 每个结果显示：
  - 柱名 + 纳甲方案（如"年柱 - 年干阴阳纳甲"）
  - 基础数
  - 展开显示详细计算过程
  - 六爻详情可视化
- 展示每个基础数对应的条文列表
- 支持下拉刷新
- 支持展开/收起详情

#### 3.1.5 八卦加则计算模块
**功能描述**: 基于四柱干支，通过八卦装配地支加则法计算条文编号

**算法原理**:
1. 取四柱干支信息（年柱、月柱、日柱、时柱）
2. 根据天干地支配卦规则，将干支转化为八卦
   - 天干配卦：壬甲从乾数，乙癸向坤求，庚来震上里，辛在巽方留，己从离门起，戊以坎为头，丙须艮处出，丁向兑家收
   - 地支配卦：亥子坎宫寊木震，巳午离门丑在坤，卯酉乾金辰是兑，未申艮宫戌巽真
3. 组卦：天干为上卦，地支为下卦，得出四柱的四个卦象
4. 每卦装配六爻地支（两种方法）：
   - **方案A - 爻序法**：从上到下，阳爻依次配（子、寅、辰、午、申、戌），阴爻依次配（丑、卯、巳、未、酉、亥）
   - **方案B - 纳甲法**：使用传统六爻纳甲规则进行配置（不区分年干阴阳）
5. 将六爻每爻的地支配上对应的数字（yaoDiZhiNumberMapper），六个数相加得到总数
6. 计算条文数：上卦后天数（作为千位）+ 总数 - 下卦后天数
7. 每柱产生2个基础数（爻序法1个 + 纳甲法1个），四柱共8个基础数
8. **不扩展条文列表**：直接使用8个基础数作为条文编号

**详细需求**:
- 输入：八字四柱（EightChars对象）
- 输出：8个基础数（4柱 × 2方法），每个基础数即为条文编号
- 特点：
  - 每个基础数不扩展为条文列表
  - 每个结果携带详细的计算过程信息
  - 区分爻序法和纳甲法
  - 标注来源柱（年/月/日/时）

**计算过程数据**:
- 柱名称：年柱/月柱/日柱/时柱
- 干支：如"甲子"
- 算法方法：爻序法/纳甲法
- 上卦：卦名及后天数
- 下卦：卦名及后天数
- 六爻详情：
  - 爻位（初、二、三、四、五、上）
  - 阴阳性（阳/阴）
  - 配上的地支
  - 该地支的数字
- 六爻总和
- 计算公式：如"6000 + 270 - 2 = 6268"
- 最终条文数

**用户交互**:
- 展示8个计算结果（分组显示）
- 每个结果显示：
  - 柱名 + 算法方法（如"年柱 - 爻序法"）
  - 条文编号
  - 展开显示详细计算过程
  - 六爻卦象可视化
- 支持下拉刷新
- 支持展开/收起详情

## 5. 技术架构

### 5.1 架构模式
采用Clean Architecture + MVVM模式：

```
Presentation Layer (UI)
├── Pages: StrategyDemoPage
├── ViewModels: DayGanZhiGuaViewModel, FourZhuTianGanViewModel, TaiXuanFourZhuViewModel, BaGuaJiaZeViewModel
└── Widgets: StrategyCard, LoadingWidget, ErrorWidget

Domain Layer (Business Logic)
├── UseCases: DayGanZhiGuaTiaoWenListUseCase, FourZhuTianGanTiaoWenListUseCase, TaiXuanFourZhuTiaoWenListUseCase, BaGuaJiaZeTiaoWenListUseCase
├── Strategies: DayGanZhiGuaStrategy, FourZhuTianGanStrategy, TaiXuanFourZhuStrategy, BaGuaJiaZeStrategy
└── Models: BaseNumberModel, BaGuaJiaZeBaseNumberModel, MultiBaseNumberResult, TiaoWenListResult

Data Layer
└── Repository: TiaoWenRepository
```

### 5.2 设计模式
- **Strategy模式**: 封装不同的计算算法
- **Template Method模式**: UseCase基类定义通用流程
- **MVVM模式**: 分离UI和业务逻辑
- **Repository模式**: 抽象数据访问
- **Provider模式**: 状态管理

### 5.3 数据流
1. UI层触发计算 → ViewModel
2. ViewModel调用 → UseCase
3. UseCase调用 → Strategy（计算基础数）
4. UseCase处理 → 条文列表计算
5. UseCase查询 → Repository（获取条文数据）
6. UseCase返回 → MultiBaseNumberResult
7. ViewModel转换 → UITiaoWenListResultModel
8. UI层更新 → 展示结果
