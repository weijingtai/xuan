## 目标
- 移除行样式中的“显示该行”开关
- 将原“内边距”改为“上下内边距”并保持联动到 V3 卡片更新

## 改动点
- 行样式面板：`common/lib/widgets/style_editor/row_style_editor_panel.dart`
  - 删除 `SwitchListTile`（显示该行）
  - 保留并重命名“显示标题”开关
  - 将“内边距 (px)”→“上下内边距 (px)”
  - 滑块仍使用 `cfg.padding` 作为垂直内边距；`onChanged: (v) => vm.updateRowStyle(cfg.type, padding: v)`
  - 不改动 `ColorfulTextStyleEditorV2Enhanced` 的调用

## 联动确认
- 行样式更新路径：
  - `updateRowStyle` 写入模板：`common/lib/viewmodels/four_zhu_editor_view_model.dart:512–551`
  - 工作区映射 VM → Notifier：`common/lib/widgets/four_zhu_card_editor_page/editor_workspace.dart:316–353`
  - V3 监听并重算尺寸：`common/lib/widgets/editable_fourzhu_card/editable_fourzhu_card_impl.dart:746–766`
- 因此“上下内边距”滑块改动会触发 V3 的 `_layoutModelSyncListener` → 尺寸与布局更新

## 兼容说明
- 暂不新增 `RowConfig` 字段，复用现有 `padding` 作为垂直内边距含义（UI 文案与语义更新）。
- 若后续需要水平/垂直分别控制，可再扩展数据模型并在 V3 渲染层分别处理。

## 验收
- Sidebar 行样式分区不再显示“显示该行”开关
- 调整“上下内边距”后 V3 卡片行间距与总尺寸即时更新，无错误提示
